# Manipulação do DOM

## Seleção: 
Use document.getElementById ou document.querySelector.

## Eventos: 
Use element.addEventListener('click', funcao) para reagir a cliques e ações do usuário.

## Alteração: 
Mude textos com:
1) element.innerHTML
2) element.textContent
3) element.insertAdjacentHTML

Mude estilos com element.style.
