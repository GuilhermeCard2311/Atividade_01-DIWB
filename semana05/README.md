1. O que é Node.js?
R:O React é executado no navegador, mas seu ambiente de desenvolvimento depende do Node.js
2. Qual a função do npm?
R: O npm é o gerenciador de pacotes do Node.js que permite instalar, compartilhar e gerenciar bibliotecas e dependências de código em projetos JavaScript.
3. Para que serve o arquivo `package.json`?
R: Armazena informações do projeto e suas dependências.
4. Qual comando cria um projeto React com Vite?
R: npm create vite@latest
5. Qual comando inicia o servidor de desenvolvimento?
R: npm run dev
